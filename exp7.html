01實驗概覽

本實驗分為兩大部分：第一部分使用 Michelson 干涉儀（雙光束干涉），第二部分使用 Fabry–Perot 干涉儀（多光束干涉）。兩者的共同核心都是利用光程差改變所造成的干涉條紋變化，將不易直接量測的物理量，轉化為可數的明暗條紋移動數。

Michelson 干涉儀

02Michelson 干涉儀

儀器架構

Michelson 干涉儀由四個核心元件組成：分光鏡（Beam Splitter）、補償鏡（Compensator）、固定鏡（Fixed Mirror）、可移動鏡（Movable Mirror）。光路如下圖所示。

圖：Michelson 干涉儀光路示意。雷射經分光鏡分為兩路：透射光通過補償鏡至可移動鏡，反射光直接至固定鏡。兩路反射回分光鏡重合後射至觀察屏。

光程差與干涉條件

將可移動鏡移動距離 d，屏幕上與光軸夾角 φ 方向的光程差為：

Δ = 2d cosφ // φ ≈ 0（軸上觀測）→ Δ = 2d 建設性干涉條件（含反射相位差 π）： 2d cosφ = (n + ½)λ

其中 ½ 項來自其中一路光在反射時多出一個 π 相位差（半波損失），並非幾何路徑多出 λ/2。不同 φ 角對應不同光程差，因此螢幕上呈現同心圓條紋（等傾干涉）。

A. 校準螺旋測微器（k 值）

螺旋測微器的刻度讀值 Δx 並非直接等於鏡面位移 d，需先以 He-Ne 雷射（已知 λ = 632.8 nm）校準比例係數 k，定義為 d = k · Δx。

k = Nλ / (2Δx) N = 計數條紋數（建議每次計 40 條） Δx = 對應螺旋測微器讀值改變量（mm） 多次測量取平均

B. 量測鈉燈 D 線波長

換光源為鈉燈，在 CCD 前放置毛玻璃，使條紋更清晰。緩慢轉動測微器，計數 N 條條紋通過固定觀察點，讀取 Δx：

λ = 2kΔx / N 建議 N = 20 或 50 條，多次測量平均

C. 觀察清晰↔模糊週期（估算 Δλ）

鈉燈 D1、D2 兩波長只差 0.6 nm，形成的兩組條紋會週期性地從清晰變模糊再變清晰。記錄兩次「最清晰」之間的鏡面位移 Δd，代入：

Δλ = λ² / (2Δd) ≈ λ₁λ₂ / (2Δd) Δd = 清晰→模糊→清晰 完整一個週期對應的鏡面位移

D. 量測空氣折射率 n₀

在一臂中放入長度 l 的空氣腔，改變腔內壓力，計數條紋總移動數 ΔN：

n₀ = 1 + λΔN / [2l(1 − P/P₀)] λ = 光源波長 l = 空氣腔長度 P = 實驗壓力, P₀ = 標準大氣壓 ΔN = 壓力變化過程中條紋總移動數
折射率公式推導

空氣折射率與壓力近似線性：n(P) = 1 + (n₀−1)·P/P₀
壓力改變 → 折射率改變 Δn = (n₀−1)(1−P/P₀)
光程差改變：ΔL = 2l·Δn（光在腔中往返兩次）
對應條紋數：ΔN = ΔL/λ → 整理得上式。

實驗步驟

Part A：Michelson 干涉儀架設圖

實際架設：雷射在左側、中央為 V 字型排列的分光鏡與補償鏡、可移動鏡在右側、固定鏡在下方、觀察屏在上方。

圖：Michelson 干涉儀架設示意。雷射從左射入分光鏡（V 左半），透射光通過補償鏡（V 右半）後至可移動鏡，反射光直接至下方固定鏡，兩路返回後在分光鏡重合並射至上方觀察屏。
  1. 架設光路、對準兩光斑
    打開 He-Ne 雷射（λ = 632.8 nm），先不放凸透鏡。
    操作調整分光鏡與兩反射鏡的高度與傾角，使兩光束在觀察屏上的光斑位置完全重合。
    判斷屏上的兩個亮斑應該疊在一起變成一個點，且光斑會閃爍或有干涉花紋。
    為什麼兩臂光束沒有疊在一起就不會干涉。先用點光源（未擴束的雷射）對準比較容易，因為光斑小、位置好判斷。
  2. 插入凸透鏡，擴束後出現同心圓條紋
    在雷射與分光鏡之間插入凸透鏡，把光束擴成一個光圈。
    操作微調固定鏡的兩個旋鈕（水平 + 垂直），直到觀察屏上的條紋變成同心圓而非斜紋或直線。
    判斷條紋形狀：同心圓 → 兩鏡幾乎垂直；橢圓或斜紋 → 兩鏡角度偏差；直線 → 偏差更大。
    為什麼擴束後光以不同角度入射，每個角度對應不同光程差，產生等傾干涉的同心圓圖案。鏡子越平行，圓心越清楚。
  3. 校準螺旋測微器（量 k 值）
    用 He-Ne 雷射，旋轉測微器讓平移台移動，計數通過固定觀察點的條紋數，講義要求總共數 200 條，可分段測量。
    讀值測微器讀值 = 主尺刻度（mm） + 旋轉套筒刻度（一圈 = 1 mm，估讀到 0.01 mm）。例如主尺 5 mm + 套筒 0.42 mm = 5.42 mm。Δx 是兩次讀值相減。
    操作朝同一方向慢慢轉，邊轉邊在心裡數通過固定參考點的暗紋或亮紋。建議分 4 段，每段 50 條，分別記錄起點與終點讀值。
    判斷每轉一點，條紋必須真的有跟著移動。若刻度改變但條紋停在原地 → 機械空回，這段不算。
    為什麼總共 200 條而非 50 條：減少計數的相對誤差。分段是因為螺旋測微器各區段機械放大率略有差異，分段可看出 k 值的均勻性，並選用實際量測會用到的區段。
    公式k = Nλ / (2Δx)，多段取平均。理論值 k = 1 mm / 25.4 μm ≈ 39.37 μm/mm。
  4. 換鈉燈，量鈉燈 D 線平均波長
    移除凸透鏡，把光源換成鈉燈。觀測方式有兩種：直接以肉眼看觀察屏、或用 CCD 鏡頭接收後在電腦螢幕上看。
    觀測肉眼：條紋直接打在觀察屏上，眼睛從適當距離看屏。優點是即時、視野大；缺點是長時間數條紋眼睛容易疲勞、容易數錯。
    CCD：CCD 鏡頭對著條紋投影面，前面加毛玻璃讓光均勻、避免眩光。電腦螢幕看條紋的好處是可放大、減少疲勞、可錄影回放對照。CCD 容易飽和，要調整曝光時間與增益。
    操作在觀察屏（或 CCD 螢幕）看到清晰條紋後，朝同一方向慢慢轉測微器，記錄起始讀值 x₁，數 50（或 100）條條紋後停下，記錄終點讀值 x₂。Δx = x₂ − x₁。
    判斷看不到條紋：可能是兩臂光程差超過鈉燈相干長度（鈉燈相干長度比雷射短很多）。先用雷射把兩臂調到大致等長，再換鈉燈。
    為什麼毛玻璃是為了把鈉燈做成擴展面光源，符合等傾干涉的觀察條件；點光源（雷射）反而看不到完整的同心圓。
    公式λ = 2kΔx / N。結果通常落在 D1 (589.592 nm) 與 D2 (588.995 nm) 之間，是兩線的有效平均波長。
  5. 觀察清晰↔模糊週期，估算雙線波長差 Δλ
    繼續同向慢轉測微器，觀察條紋對比週期性「清晰 → 模糊 → 清晰」。
    操作轉到「最清晰」位置時記錄讀值 x₁，繼續轉，下一次「最清晰」記錄 x₂。Δx = x₂ − x₁，Δd = k·Δx。
    判斷「清晰」= 兩組條紋（D1、D2）重疊時對比最強；「模糊」= 兩組條紋錯開半個週期、亮環疊暗環，條紋幾乎消失。
    為什麼兩波長分別形成自己的條紋，光程差累積到一定量時兩組相位差剛好 2π，再次重合即為清晰。完整一個週期對應 Δd 約 290 μm（依數據而定）。
    公式Δλ = λ² / (2Δd)，理論值 0.597 nm。
  6. 放入空氣腔，量空氣折射率 n₀
    把空氣腔插入可移動鏡那臂的光路上，用 He-Ne 雷射作光源。
    操作先記下大氣壓 P₀，再用抽氣裝置將空氣腔抽到較低壓力 P（記錄壓力計讀值）。緩慢洩氣回大氣壓，計數整個過程通過固定點的條紋變化數 ΔN。
    讀值壓力計顯示的是絕對壓力 P（不是表壓），P₀ = 101.325 kPa 為大氣壓。空氣腔長度 l 要實際量（用尺量腔體外殼，注意是光在腔內的實際路徑長）。
    為什麼壓力變 → 折射率變 → 該臂光程差變 → 條紋移動。空氣腔放在可移動鏡那臂的水平光路上（空間長、易插入），另一臂作為參考。
    公式n₀ = 1 + λΔN / [2l(1 − P/P₀)]，理論值 1.000293。光在腔內往返兩次，所以光程是 2l。

03Fabry–Perot 干涉儀

儀器架構與多光束干涉

Fabry–Perot 干涉儀由兩個彼此平行、高反射率的光學平面構成，中間形成可調厚度的空氣薄膜。光在兩平面間多次往返後疊加，只有在共振條件精確滿足時才出現明顯透射峰。

圖 7-2：Fabry–Perot 干涉儀原理。光在兩高反射鏡 M₁、M₂ 間多次往返，多次透射光疊加後形成尖銳的 Airy 函數型透射峰，對應觀測屏上的同心圓亮紋。

透射強度公式與 Finesse

// 透射強度（Airy 函數） Iₜ = Iᵢ(1−R)² / [1 + R² − 2R cosδ] // 相位差 δ = (2π/λ) · 2nd cosθ // Coefficient of finesse F = 4R / (1+R)² // Finesse（R > 0.5 時） ℱ ≈ π√R / (1−R) R 越大 → Finesse 越大 → 條紋越尖銳 → 分辨率越高 // Free Spectral Range（FSR） (Δλ)_fsr = λ₀² / (2nd cosθ)

量測鈉燈雙線波長差 Δλ

鈉燈 D1（589.592 nm）和 D2（588.995 nm）各自形成一組同心圓條紋。改變板距 d，兩組條紋會週期性地「重合 → 交錯 → 再重合」。記錄兩次重合之間的板距差 Δd：

Δλ = λ₁λ₂ / (2Δd) Δd = 兩次條紋「重合」之間的板間距改變量 λ₁ = 589.592 nm, λ₂ = 588.995 nm（使用理論值）

Δλ 公式推導

推導

方法一（本實驗報告常用寫法）：兩組條紋從重合到下一次重合，等效於 λ₁ 的條紋剛好比 λ₂ 多移動了一個完整週期：

2Δd/λ₁ − 2Δd/λ₂ = 1 ⟹ 2Δd·(λ₂−λ₁)/(λ₁λ₂) = −1 ⟹ Δλ = λ₁λ₂ / (2Δd)

方法二（條件疊合法）：設板距 d 時，λ₁ 的第 m 階與 λ₂ 的第 m+1 階重合 → 2d = mλ₁ = (m+1)λ₂ → m = λ₂/Δλ → 代入下一次重合條件，同樣可得 Δλ = λ₁λ₂/(2Δd)。

實驗步驟

Part B：Fabry–Perot 干涉儀架設圖

圖 7-2：Fabry–Perot 干涉儀架設示意。鈉燈經毛玻璃形成擴散光源，光在兩高反射鏡 M₁、M₂ 間多次往返後，透射光經透鏡聚焦於 CCD 形成同心圓條紋。M₂ 由螺旋測微器控制，可改變板間距 d。
  1. 調整兩鏡平行，建立同心圓條紋
    以鈉燈加毛玻璃照明 F-P 干涉儀。觀測可用肉眼直接看屏、或用 CCD 接收後在電腦螢幕看（後者較不費眼）。
    觀測肉眼：從觀察屏正面看圓條紋，方便快速調整鏡子角度。
    CCD：條紋更穩定、可放大細節、判斷「重合 vs 交錯」更準。F-P 條紋極尖銳，CCD 曝光時間要調整避免過曝或過暗。
    操作調整可調鏡 (Adjustable Mirror) 後方的兩個微調旋鈕，慢慢改變鏡子的水平與垂直傾角，直到觀察螢幕上出現清晰的同心圓條紋。
    判斷兩鏡越平行，條紋越尖銳對比越高。若條紋是橢圓或斜紋 → 兩鏡不夠平行；若完全沒有條紋 → 角度差太多，先把鏡子拉到大致 0° 再微調。
    為什麼F-P 是多光束干涉，需要光在兩鏡間多次往返才能形成尖銳條紋。兩鏡不夠平行 → 光偏出去就不再往返 → 多光束變兩光束 → 對比下降。
  2. 辨識「重合」與「交錯」狀態
    緩慢轉測微器改變兩鏡距離 d，觀察條紋對比的週期變化。
    操作先轉幾圈試試，讓眼睛習慣條紋對比變化的速度；同時觀察條紋有無真的因應測微器轉動而動。
    判斷「重合」 = 兩組同心圓亮環疊在一起，看起來只有一組清晰條紋。「交錯」 = 兩組亮環錯開，亮環密度看起來變兩倍但亮度與對比下降，整體偏灰。
    為什麼D1 與 D2 各自有一組條紋，因為波長極相近，兩組圓的半徑略有不同。隨著 d 改變，兩組條紋的相位差累積，會週期性「重合 → 錯開 → 重合」。
  3. 記錄兩次「重合」之間的板距差 Δd
    從第一次重合的位置記讀值 x₁，繼續同向慢轉，等下一次完全重合再記 x₂。
    操作每次「重合」要前後微調確認那是對比最強的位置（不是中間位置）。記錄 x₁、x₂ 後 Δx = x₂ − x₁，Δd = k·Δx。建議多測 2-3 次取平均。
    判斷「最清晰」的判斷較主觀，可同時數中間經過幾次完整的「重合 → 模糊 → 重合」週期來校驗。
    為什麼板距改變 Δd 期間，兩波長的相位差累積一個完整週期 2π，相當於 λ₁ 與 λ₂ 的條紋階數差 1。由此可反推 Δλ。
    公式Δλ = λ₁λ₂ / (2Δd)，理論值 0.597 nm。F-P 比 Michelson 更精準是因為條紋更尖銳，重合位置判斷誤差更小。

04問題與討論

以下為講義要求的思考與討論題目完整解答，點擊展開。

思考與預測

Q1：為何要將 Michelson 兩臂調整到大致相等的長度？ +

原因：相干長度限制

真實光源的相干長度（Coherence length）有限。He-Ne 雷射相干長度可達數十公分到數公尺，鈉燈則只有幾 mm 到 1 cm 左右（單模雷射 vs 寬譜燈源）。若兩臂路程差超過光源的相干長度，兩束光到達觀測屏時的相位關係已不再穩定，干涉條紋的對比度（Visibility）會下降甚至完全消失。

等長的好處：

  • 光程差趨近零 → 遠小於相干長度 → 條紋穩定清晰
  • 兩臂幾何像差相互對稱 → 減少系統誤差
  • 用 He-Ne 對好等長後再換鈉燈，可大幅降低看不到條紋的機率

實驗中的具體現象：若雷射下看得到條紋、換鈉燈卻看不見，最可能原因就是兩臂差距超過鈉燈相干長度。可先用尺粗估兩臂長度，相差控制在 5 mm 以內。

Q2：補償鏡的功能為何？ +

原因：兩臂通過玻璃的次數不對稱

分光鏡是一塊玻璃板，鍍膜面只有一面。從雷射射入後：

  • 到可移動鏡那臂的光：穿透分光鏡 1 次 → 反射回來再穿透 1 次 = 穿過玻璃 2 次（但少一次穿過鍍膜層）
  • 到固定鏡那臂的光：在分光鏡鍍膜面反射 → 反射回來再反射 = 完全沒穿過玻璃

結果是「到可移動鏡那臂」多穿了 2 倍玻璃厚度，引入額外光程差（玻璃折射率 ≠ 空氣折射率）。此外不同波長在玻璃中折射率不同（色散），會造成寬譜光源的條紋對比下降。

補償鏡的作用：放在「沒穿過玻璃那臂」（即固定鏡那臂），是一片與分光鏡材質、厚度完全相同的玻璃。讓兩臂通過的玻璃總厚度相等（光路對稱），消除：

  • 額外光程差 → 量測的光程差才純粹來自鏡面位移或折射率改變
  • 色散造成的條紋對比下降 → 鈉燈或白光下也能看到清晰條紋

結報常見錯誤：把補償鏡寫成「在分光鏡同一臂」，或寫「補償鏡也是分光的」。實際上補償鏡只是普通透明玻璃，不分光、不鍍膜。

Q3：建設性干涉條件為何是 (n + ½)λ 而非 nλ？ +

原因：反射時的 π 相位跳躍（半波損失）

光從光疏介質（折射率小）射向光密介質（折射率大）反射時，反射波相位反轉 π，等效於多出半個波長 λ/2 的光程。這是 Fresnel 反射係數的結果：

r₁₂ = (n₁ − n₂) / (n₁ + n₂) 若 n₂ > n₁ → r < 0 → 反射波相位反轉 π

在 Michelson 中：兩束光的反射經歷不完全相同。其中一束在分光鏡的鍍膜面從空氣端反射（疏→密），另一束從玻璃內側反射（密→疏，不反相），兩臂之間多出一個 π 的相對相位差，等效於多出 λ/2 的光程差。

修正條件：原本純幾何整數倍條件 Δ = nλ，加入這半波長修正，變成：

建設性干涉：2d cosφ = (n + ½)λ 破壞性干涉：2d cosφ = nλ

注意：這個 ½ 是反射時的相位效應，並非兩臂幾何路程真的多出 λ/2。實驗上我們只關心「相對」的條紋移動數，這個常數半波長並不影響量測。

Q4：如何確認旋轉螺旋測微器時，平移台真的有在移動？ +

原因：機械空回（Backlash）

螺旋測微器與平移台之間的螺紋傳動有公差。當旋轉方向改變時，螺紋需先「貼合」到另一側才會真正帶動平移台，這段「轉動了但平移台不動」的範圍稱為空回，可能達數十條條紋。

判斷方法：

  • 不能只看測微器刻度有沒有變，要觀察干涉條紋是否同步移動。
  • 轉動測微器，若條紋立即連續移動 → 平移台確實在動。
  • 若刻度改變但條紋停在原地 → 仍在空回段，這段讀值不算。

實驗中如何避免：

  • 全程朝同一方向旋轉，絕不反轉。
  • 校準 k 值與量波長要在同一方向、同一段刻度範圍內進行。
  • 若不小心反轉了，要先朝原方向多轉幾條條紋確認跳出空回段，才能繼續計數。

問題與討論

Q5：為何 Michelson 不容易量測鈉燈兩波長差 Δλ，而 Fabry–Perot 可以？ +

核心差異：條紋的尖銳程度

鈉燈 D1、D2 兩波長差僅約 0.6 nm。

Michelson 是雙光束干涉，條紋強度分布為餘弦型 I ∝ (1 + cos δ)，峰值寬且平緩。兩組相近波長的條紋幾乎完全重疊，無法直接分辨。雖可觀察清晰↔模糊週期估算 Δλ，但判讀「最清晰」位置主觀性大、誤差大。

Fabry-Perot 是多光束干涉，透射條紋為 Airy 函數型，峰值極尖銳。Finesse 公式：

ℱ = π√R / (1−R) （R 為鏡面反射率） 例：R = 0.85 → ℱ ≈ 19 例：R = 0.95 → ℱ ≈ 61

Finesse 越大，條紋越尖、能分辨的最小波長差越小。Fabry-Perot 因為光在兩鏡間多次往返，等效「無限多束光干涉」，條紋極尖；Michelson 只有兩束光，等效 Finesse ≈ 2，分辨力差很多。

實驗上的差異：F-P 量出來的 Δλ 通常更接近理論值 0.597 nm，誤差約 3–20%；Michelson 量 Δλ 誤差可達 15% 以上（看「最清晰」判讀有多準）。

Q6：為何 Fabry–Perot 干涉儀無法直接量測鈉燈的絕對波長 λ？ +

原因：階次 m 與板距 d 都無法直接得知

F-P 的條紋共振條件：

2d cosθ = mλ

單看一組條紋，要算出 λ 必須同時知道：

  • 整數階次 m：實驗中通常很大（可達數萬），無法直接從條紋計數得到絕對值。
  • 精確板距 d：F-P 鏡距校準誤差通常在 μm 量級，乘上大 m 後波長誤差會放大。
  • 入射角 θ：每條同心圓亮環對應不同 θ，但 θ 也無法直接量。

三個未知量無法只靠條紋位置求出 λ。

對比 Michelson：每移動鏡面 λ/2，就有一條條紋通過。條紋數 N 直接對應到光程差 Nλ，不需要知道 m 的絕對值，只需要知道相對變化。因此 Michelson 可量絕對波長，F-P 只能量「兩組條紋的相對差值 Δλ」（這時 m 的不確定性可以消去）。

實驗中為何 m 難測：F-P 鏡距 d 通常幾 cm，m = 2d/λ 對 λ = 589 nm 大約是 10⁵ 階。要量到 m 必須讓 d 變到很小（例如 0），再從 d=0 開始計數，但機械上做不到。

Q7：導出 Δλ = λ₁λ₂ / (2Δd) +

從「兩組條紋重合後，Δd 內 λ₁ 比 λ₂ 多走一個完整週期」出發：

2Δd/λ₁ − 2Δd/λ₂ = 1 ⟹ 2Δd · (λ₂ − λ₁)/(λ₁λ₂) = −1 取絕對值（定義 Δλ = λ₁ − λ₂ > 0）： Δλ = λ₁λ₂ / (2Δd)

物理意義：Δd 越小代表 Δλ 越大（兩波長差越大，條紋重新對齊所需的板距差越小）。

Q8：導出 n₀ = 1 + λΔN / [2l(1 − P/P₀)] +

由理想氣體近似，折射率與壓力線性：

n(P) = 1 + (n₀ − 1) · P/P₀ ⟹ Δn = n₀ − n(P) = (n₀ − 1)(1 − P/P₀) 光在腔中往返，光程差改變： ΔL = 2l · Δn 對應條紋移動數 ΔN： ΔN = ΔL/λ ⟹ λΔN = 2l(n₀ − 1)(1 − P/P₀) 解出 n₀： n₀ = 1 + λΔN / [2l(1 − P/P₀)]
