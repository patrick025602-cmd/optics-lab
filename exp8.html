Part A：遠場與近場繞射

觀察 Airy disk，建立孔徑形狀與繞射圖樣的對應

判斷近場 vs 遠場

以 Fresnel Number 判斷適用哪種繞射模型：

F = a² / (L λ) a = 孔洞半徑，L = 孔洞到屏幕距離，λ = 波長（633 nm）
  • F ≥ 1（近場 Fresnel）：光源球面波入射，屏幕距孔徑較近
  • F ≪ 1（遠場 Fraunhofer）：可視為平面波，用透鏡平行擴束

🎯 A-1：遠場繞射實驗步驟

估算 pin hole 直徑，觀察各繞射孔徑圖樣

圖 A-1：遠場繞射光路 — Lens 移除，Spatial Filter 後置入孔徑，屏幕距離 L 記錄繞射圖形
  1. 1
    移除 Lens，調整 Spatial Filter

    移除光路中的透鏡，調節 spatial filter 前後左右位置，使 pin hole 的繞射圖形（Airy disk）清楚顯現在屏幕上。

  2. 2
    量測 Airy disk 估算 pin hole 直徑

    量取中央亮斑半徑 r（中心到第一暗環的距離）以及 pin hole 到屏幕距離 L，代入：

    D ≈ 1.22 × λ × L / r   （r = 中央亮斑半徑，sin θ ≈ r/L）
  3. 3
    依序觀察各繞射孔徑

    將下列孔徑依序放入光路，觀察並記錄繞射圖樣：
    → 單狹縫 → 多狹縫 → 光柵（多個） → 細方格陣列 (fine gauze)

由 r ≈ 1.22λL/D 可知 r 與 L 為線性正比關係，斜率為 1.22λ/D。三組數據點貼近理論直線，斜率反推 D ≈ 9.57 μm。

⚙️ 反推幾何尺寸的核心公式

① 圓孔（Airy disk）：

D ≈ 1.22 λL / r   （r = 中央亮斑半徑，sin θ ≈ r/L）

② 雙／多狹縫間距：

d sin θ = mλ   （小角近似 sin θ ≈ Δy/L）

③ 單狹縫寬度：

a sin θ = mλ   （中央亮紋第一暗點位置）

🎯 A-2：近場繞射實驗步驟

球面波入射，觀察 Fresnel 繞射結構

圖 A-2：近場繞射光路 — 屏幕緊靠孔徑，觀察 Fresnel zone 的亮暗交替
  1. 1
    架設近場繞射光路

    調整空間濾波器使雷射光束通過後產生球面波。將可調圓孔或可調狹縫放置在靠近空間濾波器出口處。

  2. 2
    記錄參數並觀察

    記錄圓孔半徑 a、屏幕距離 L，計算 Fresnel Number F，對應觀察屏幕中心亮/暗的變化。

  3. 3
    調整孔徑大小，觀察中心亮暗變化

    改變圓孔半徑或狹縫寬度，記錄屏幕中心附近光強度的亮暗交替現象。當光圈大時 F 大，圖樣較均勻；光圈縮小時 F 減小，繞射效應顯著，可見清晰同心圓干涉條紋。

近場繞射 — 光圈大小效應

較大光圈：螢幕呈現一較寬廣且強度均勻的亮區，干涉條紋不明顯（F 較大，接近幾何光學）。

較小光圈：觀察到清晰的同心圓狀干涉條紋，繞射效應顯著增強（F 減小，波動效應變強）。

建議實驗：用可調圓孔依序取三組尺寸（例：0.75 mm、1.25 mm、1.75 mm）；可調狹縫亦可比較，狹縫產生一維方向延展的非等向 Fresnel 圖樣。屏幕距 L 約 1 m。

Part B：DNA 螺旋結構繞射圖形

用小彈簧模擬 DNA 雙螺旋，由繞射圖反推幾何結構

為什麼用小彈簧？

DNA 雙螺旋的結構尺寸在奈米等級（直徑 ≈ 2 nm，pitch ≈ 3.4 nm），可見光波長太長無法解析。實驗以小彈簧（毫米尺度）模擬螺旋幾何，用 He-Ne 雷射觀察類似的 X 字型繞射圖案，這正是 Rosalind Franklin 拍攝的 Photo 51 中所見的特徵。

🎯 實驗步驟

  1. 1
    重複 Part A 遠場繞射光路，用小彈簧取代孔徑

    將小彈簧放置在光路箭頭處（spatial filter 後，lens 前）。觀察屏幕上出現的 X 字型繞射條紋，且沿亮線分布有規律排列的亮點。

  2. 2
    量測繞射圖形，推算幾何結構

    量取兩條斜向繞射亮帶之夾角 2α（α 為螺距角），並依參考資料說明，由繞射圖樣中亮點間距、極小值位置推算彈簧之線材厚度與螺距。

  3. 3
    與游標卡尺直接量測比較

    用直尺或游標卡尺直接測量小彈簧的螺距 P、線徑 a、半徑 R，與步驟 2 由繞射推算的數值比較，評估誤差。

  4. 4
    （Optional）電腦模擬 DNA 繞射圖形

    使用程式模擬畫出 DNA 的理論繞射圖形，與實際觀察比較。

小彈簧繞射圖樣特徵

除中央主極大外，沿對角線方向延伸出明顯的 X 形亮線。這是螺旋結構在頻域中的特徵繞射圖樣，與真實 DNA X-ray 繞射所見的「Photo 51」拓樸相同。

繞射圖樣視覺化 — 物體 vs 屏幕
物體：小彈簧（螺旋）

螺距 P，pitch angle α

屏幕：X 形繞射圖樣

中央極亮 + 兩條斜向繞射射線

螺旋結構在頻域中產生 X 形繞射，是螺旋繞射的標誌性特徵。

Part C：傅氏光學實驗

透鏡將遠場繞射理解為傅立葉轉換

核心原理

本實驗的核心是 Abbe 雙重繞射成像：透鏡 L1 把物體的繞射光在後焦面（PL2）上組成空間頻譜（傅氏轉換）；L2 再把這個頻譜逆向變回實空間影像（PL3）。

  • L1（傅氏轉換透鏡）：物體放在 L1 前焦面（距 L1 = f₁），L1 後焦面 = 傅氏平面 PL2
  • L2（反傅氏轉換透鏡）：距 L1 = f₁ + f₂，L2 後焦面 = 還原影像平面 PL3
  • 實驗室透鏡焦距：f₁ = f₂ = 10 cm。L1 ↔ L2 距離固定 20 cm，物體距 L1 為 10 cm，屏幕距 L2 也是 10 cm。

傅氏平面上：靠近中心 → 低空間頻率（物體粗大、整體輪廓）；遠離中心 → 高空間頻率（細節、邊緣、密集週期）。

Uf(fx, fy) ∝ ∬ U(x,y) · e−i2π(fxx + fyy) dx dy fx = xf / (λf)，傅氏平面上的位置 ↔ 物體的空間頻率

🎯 光路架設（圖 8-2 / 4f 系統）

從左到右依序：Laser → Spatial Filter → 物體 → L1 → 傅氏平面 → L2 → 屏幕

圖 8-2：傅氏光學完整光路 (4f system) — 物體在 L1 前焦面，L2 距 L1 共 20 cm，屏幕在 L2 後焦面（最右側）
⚙️ 元件擺位口訣（學生最常問）
元件位置怎麼分辨？
物體L1 前 10 cm放粗/細方格時要垂直入射，避免歪斜
L1（傅氏轉換）物體後 10 cm兩片透鏡長得一樣！只能用順序分：靠近物體那片 = L1，靠近屏幕那片 = L2
L2（反傅氏轉換）L1 後 20 cm
PL2 傅氏平面L1 後 10 cm（剛好夾在 L1 與 L2 中間）濾片要放這裡（見 Part D）；現在只是「概念位置」，不放東西
屏幕（PL3）L2 後約 10 cm（最右側）影像不清楚時，只前後微調屏幕，不要動 L1/L2

系統別名「4f system」的由來：總長 = f + f + f + f = 4f = 40 cm（物體到屏幕）。

  1. 1
    先只放 L1，觀察傅氏平面上的頻譜

    怎麼做：把 L2 拿開。放上粗方格（target mesh）為物體，L1 距物體 10 cm，屏幕暫時放在 L1 後 10 cm 處（這個位置就是 PL2 傅氏平面）。
    看什麼：屏幕上應該出現二維點陣 — 很多紅色亮點排成水平＋垂直格子狀，中心最亮、向外遞減。這就是物體的空間頻譜。
    為什麼這樣做：先驗證 L1 對準光軸、物體垂直、頻譜清楚成形，再放 L2，才不會把對準問題與成像問題疊在一起難以排查。

  2. 2
    換成細方格 (fine gauze)，比較兩種頻譜

    看什麼：粗方格 → 點陣密集、集中於中心；細方格 → 點陣間距變大、亮點延展到外圍十字方向。
    為什麼：頻譜亮點位置 xf = λ·f / d，與物體週期 d 成反比。粗方格 d 大 → xf 小；細方格 d 小 → xf 大。
    拍照重點：同一張屏幕、同一個距離下拍兩張頻譜圖對照，學生才看得出間距差異。

  3. 3
    放入 L2 做反傅氏轉換，重建影像

    怎麼做：把屏幕往後移開，在 L1 後 20 cm 處插入 L2（也就是 L1 與 L2 之間距離 = 20 cm = f₁ + f₂）。屏幕繼續往後移到 L2 後約 10 cm，前後微調直到重建影像最清楚。
    看什麼：屏幕上應該重現出原始方格圖案（亮暗格子）。如果只看到一團紅光、沒有方格結構 → 微調屏幕位置即可。
    常見卡點：

    • L1 ↔ L2 距離 ≠ 20 cm → 影像永遠模糊（這個距離是固定的，不能調）
    • 物體沒有在 L1 前焦面 10 cm 處 → 重建影像殘留繞射條紋、邊緣不純
    • 屏幕太遠 → 影像放大但散開；太近 → 縮小、邊緣不清
    • 方格陣列歪斜放置 → 重建影像方格也跟著轉

  4. 4
    記錄重建影像的失真

    看什麼：重建影像與原物體相比，邊緣比較不銳利、對比度下降、細節變模糊。
    為什麼（學生會問）：L2 的孔徑（透鏡邊界）有限，會切掉繞射角太大的高頻成分。原物體的銳利邊緣 = 高頻訊號 → 高頻被截斷 → 邊緣平滑化。這是光學的本質極限（Optical resolution limit），不是儀器沒調好。
    觀察比較：細方格的失真比粗方格更嚴重 — 因為細方格本身就含更多高頻成分，被切掉的比例更大（這正是問題討論 Q5 要回答的）。

Fine Gauze 的傅氏圖樣特徵

fine gauze 是二維週期結構（x、y 方向都有週期性的紗網），可視為兩個正交的一維光柵相乘。在傅氏平面上呈現水平 + 垂直十字亮點陣，中心最亮、向外遞減。亮點間距由紗網週期決定。

粗 vs 細方格陣列比較
特性粗方格 (Target Mesh)細方格 (Fine Gauze)
實空間週期 d大（粗）小（細）
主要空間頻率低高
傅氏平面亮點間距小（密集集中於中心）大（外展）
傅氏平面亮點數量少（外圍快速衰減）多（高階亮點明顯）
反傅氏重建失真較小（低頻能完整通過 L2）較大（高頻被 L2 孔徑截斷）

關鍵公式：傅氏亮點位置 xf = λ·f / d。代入 λ = 633 nm、f = 10 cm，從拍照量到的亮點間距即可反推物體週期 d。

Part D：光學信號處理（空間濾波）

在 Fourier Plane 加入濾波器，直接操控空間頻率

空間濾波原理

在 Fourier Plane 放置不同濾波元件，可以選擇性保留或去除特定空間頻率成分，進而改變重建影像的外觀。這是光學影像處理的基本操作。

圖 8-3：空間濾波光路 — 在 Fourier Plane 放入濾波元件（高通／低通／狹縫），改變重建影像

🎯 D-1：方向性濾波（狹縫）

  1. 1
    以 fine gauze 為物體

    在 Fourier Plane 上可觀察到二維點陣分布（對應 2D 週期結構的頻譜）。

  2. 2
    放入可調寬度狹縫

    在 Fourier Plane 放入可調狹縫，只讓某一方向的部分繞射點通過，遮擋其他方向。

  3. 3
    觀察：2D 光柵 → 1D 光柵

    重建影像將由原本的二維週期結構變為單一方向的一維週期結構。

🎯 D-2：高通濾波（High-Pass Filter）

  1. 1
    改用較大孔徑物體（打孔卡片或英文字母）

    在 Fourier Plane 加入高通濾波器（擋住中心低頻，讓高頻通過）。

  2. 2
    觀察：輪廓強調效果

    低頻被遮擋，重建影像強調輪廓與邊界（邊緣增強，類似影像銳化）。

🎯 D-3：低通濾波（Low-Pass Filter）

  1. 1
    換成低通濾波器

    在 Fourier Plane 改用低通濾波器（只讓中心低頻通過，遮擋高頻）。

  2. 2
    觀察：平滑化效果

    高頻被遮擋，重建影像邊界模糊、細節消失（類似影像模糊化）。

問題討論（參考解答）

點擊問題展開解答

Q1. 近場繞射中，屏幕光譜分布和 Fresnel number 的關係為何？分中心點和外圈討論。 +

F = a²/(Lλ) 是判斷近場／遠場的無因次量。

中心點：F 大時亮度較穩定且接近幾何投影；F 較小時，中心亮度可能隨孔徑或距離變化在亮、暗之間振盪，由各 Fresnel zones 的相位疊加決定。

外圈：F 大時主要呈現幾何陰影邊界；F 減小時環紋逐漸明顯；F ≪ 1 時收斂為 Fraunhofer 圖樣。

整體趨勢：F 越小，波動效應越顯著。

Q2. 真實的 DNA 結構分析需要使用 X-ray，原因為何？ +

解析能力受波長限制：要解析尺度 d 的結構，須有 λ ≲ d。

  • DNA 結構尺度：鹼基間距 3.4 Å、雙螺旋直徑 20 Å
  • 可見光 λ ≈ 400–700 nm，比 DNA 大 1000 倍 → 完全無法解析
  • X-ray λ ≈ 0.1–1 nm，與分子尺度相當 → 可產生有結構資訊的繞射

本實驗用毫米級彈簧重現「螺旋 → X 形繞射」的拓樸特徵，但要看真正的 DNA 必須換尺度匹配的光源（X-ray 或冷凍電鏡）。

Q3. 實驗 C 中，傅式轉換影像較接近 Fresnel 或 Fraunhofer 繞射圖形？ +

較接近 Fraunhofer。

關鍵：透鏡的二次相位項 e−ikr²/2f 剛好抵銷 Fresnel 積分中那項二次相位。抵銷後剩下的就是純 Fourier kernel，因此 L1 焦平面上看到的就是物體的 Fraunhofer 繞射，但無需把屏幕架到無窮遠。

一句話：透鏡 = 把無限遠的 Fraunhofer 圖樣壓縮到焦平面的工具。

Q4. 傅式轉換實驗中，粗方格陣列與細方格陣列，圖案粗細與傅氏分布的關係？ +

實空間 ↔ 頻域：互為倒數關係。

  • 疏密（週期 d）：亮點間距 ∝ 1/d。粗格 → 點靠近；細格 → 點散開
  • 線粗細（縫寬 a）：包絡寬度 ∝ 1/a。線粗 → 包絡窄、高階快速衰減；線細 → 包絡寬、高階點看得多
  • 方向：物體旋轉 θ → 頻譜也旋轉 θ（FT 旋轉不變性）

口訣：細密外展、粗疏集中；線細包絡寬、線粗包絡窄。

Q5. 反傅氏轉換實驗中，粗方格與細方格的影像失真狀況有何不同？ +

關鍵：誰的「主能量」落在被遮的頻段，誰失真嚴重。

粗方格（低頻為主）細方格（高頻為主）
低通濾波幾乎無失真紋理消失，糊成一片
高通濾波輪廓消失，僅剩邊緣整體變暗但紋理仍可辨

實作意涵：真實光學系統有截止頻率（孔徑、像差限制），高頻容易被截斷，所以細方格的反傅氏轉換普遍比粗方格失真更明顯。
